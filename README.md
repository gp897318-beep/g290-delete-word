## The word

**never**

Delete it and nobody can ever say "never" again — not even "never say
never". The joke lands in one beat, comes entirely from the word's own
meaning, and needs no caption: the deletion defeats itself. It is also
the opposite of the field's obvious picks (moist, literally,
irregardless), so it stays fresh.

## How it works

`main.ts` validates the gate (exactly one word, 1–77 characters, letters
only) and writes the word to `/output/entry.txt`.

```sh
node main.ts
cat /output/entry.txt   # never
```
